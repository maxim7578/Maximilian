# Instagram-Daten

Arbeitsdateien der Instagram-Skills (`/ig-*`). In Cloud-Sessions zeigt
`~/.claude/instagram/` hierher (siehe `.claude/hooks/session-start.sh`).

- `voice.md`: deine Stimme, von allen Skills gelesen. Vorlage:
  `.claude/instagram-agent-skill/templates/voice.md`
- `plan.md`: Wochenplan von `/ig-plan`
- `swipe.md`: Swipe-Datei von `/ig-viral`
- `log.md`: was gepostet und kommentiert wurde
